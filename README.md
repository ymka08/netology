Однако гетерогенная среда может быть оправдана, если необходимо использовать преищуества разных гипервизоров или происходит переход с одной платформы на другую или подразделения компании имеют существенно отличающиеся требования. Гетерогенную среду имеет смысл создавать только тогда, когда её преимущества перевешивают дополнительные затраты на администрирование и поддержку.
